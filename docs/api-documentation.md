# AgriGuide AI – REST API Documentation

Base URL: `/api/v1`

All protected routes require an `Authorization: Bearer <access_token>` header, where the token is generated by Supabase Auth on the client.

---

## 1. Health Check
- **`GET /api/v1/health`**
  - **Auth**: Public
  - **Response 200**:
    ```json
    {
      "success": true,
      "message": "AgriGuide AI API is operational",
      "data": {
        "status": "healthy",
        "timestamp": "2026-11-06T18:00:00.000Z",
        "geminiConfigured": true,
        "supabaseConfigured": true
      }
    }
    ```

---

## 2. Farmer Profile
- **`GET /api/v1/profile`**
  - **Auth**: Authenticated
  - **Response 200**: Returns user profile from `profiles` table.

- **`PUT /api/v1/profile`**
  - **Auth**: Authenticated
  - **Body**:
    ```json
    {
      "fullName": "Ramesh Kumar",
      "phone": "+91 9876543210",
      "state": "Karnataka",
      "district": "Dharwad",
      "village": "Navalgund",
      "preferredLanguage": "kn",
      "farmingExperience": 12,
      "totalLandArea": 5.5,
      "landMeasurementUnit": "acre"
    }
    ```

---

## 3. Land & Soil Management
- **`GET /api/v1/lands`**: List all land parcels owned by authenticated farmer.
- **`POST /api/v1/lands`**: Register new land parcel with soil characteristics.
  - **Body**:
    ```json
    {
      "landName": "North Field Plot 1",
      "area": 3.5,
      "areaUnit": "acre",
      "state": "Karnataka",
      "district": "Dharwad",
      "village": "Navalgund",
      "soilType": "Black Soil",
      "soilPh": 7.4,
      "nitrogen": 190,
      "phosphorus": 35,
      "potassium": 240,
      "soilMoisture": 32,
      "irrigationAvailable": true,
      "previousCrop": "Soybean"
    }
    ```
- **`GET /api/v1/lands/:id`**: Get single land details.
- **`PUT /api/v1/lands/:id`**: Update land attributes.
- **`DELETE /api/v1/lands/:id`**: Remove land parcel.

---

## 4. Crop Catalogue
- **`GET /api/v1/crops`**: Returns list of all agricultural crops in catalogue.
- **`GET /api/v1/crops/:id`**: Detailed crop information.

---

## 5. Crop Advisory
- **`POST /api/v1/advisory/crop`**
  - **Auth**: Authenticated
  - **Body**:
    ```json
    {
      "landId": "uuid-optional",
      "state": "Karnataka",
      "district": "Dharwad",
      "soilType": "Black Soil",
      "soilPh": 7.2,
      "nitrogen": 180,
      "phosphorus": 35,
      "potassium": 220,
      "landArea": 2.5,
      "areaUnit": "acre",
      "season": "Kharif",
      "waterAvailability": "moderate",
      "previousCrop": "Groundnut",
      "preferredCategory": "Pulses",
      "language": "en"
    }
    ```
  - **Response 200**:
    ```json
    {
      "success": true,
      "message": "Crop recommendations generated successfully",
      "data": {
        "summary": "...",
        "recommendations": [
          {
            "cropName": "Pigeon Pea (Tur)",
            "suitabilityScore": 92,
            "confidence": "high",
            "reasons": ["Deep taproot thrives in black soil", "Fixes nitrogen after groundnut"],
            "soilCompatibility": "Excellent for Vertisols",
            "waterRequirement": "Low to Moderate",
            "growingSeason": "Kharif",
            "importantConsiderations": ["Watch for pod borer during flowering"]
          }
        ],
        "soilObservations": ["Balanced pH suitable for pulses"],
        "missingInformation": [],
        "nextSteps": ["Procure certified wilt-resistant seed varieties"],
        "disclaimer": "Recommendations are decision-support estimates."
      }
    }
    ```

- **`GET /api/v1/advisory/history`**: Paginated history of farmer's previous advisories.
- **`GET /api/v1/advisory/:id`**: Fetch specific previous advisory.
- **`DELETE /api/v1/advisory/:id`**: Delete advisory record.
